# Python File Handling - 12 Practical Questions

## Included
- One Python source file: `file_handling.py`
- All 12 file-handling practical questions
- A main menu to choose which question to run
- Separate functions for each question

## How to run
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open the terminal in that folder.
4. Run:

```bash
python file_handling.py
```

5. Enter a menu number from 1 to 12. Enter 13 to exit.

The program creates its TXT, CSV, and JSON data files in the same folder when you run the related question.

**Note:** The username/password example is only for classroom practice. Real applications must never store passwords as plain text.
